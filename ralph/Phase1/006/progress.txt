### 2026-03-02: Mapping Inconsistency Fix Attempt
- Modified environment to use simulator.compute_energy with molecule Hamiltonian, ensuring correct transformation used for energy evaluation.
- This resolves Hamiltonian-circuit mapping inconsistency at energy evaluation level.
- However circuit builder still uses UCCSD (Jordan-Wigner mapping) which produces circuits with different qubit count than parity Hamiltonian.
- Attempted to conditionally create UCCSD object only for Jordan-Wigner transformation, but UCC object lacks excitation operators.
- Tencirchem's UCCSD only supports Jordan-Wigner mapping, making parity transformation incompatible with current circuit builder.
- Decision: Use Jordan-Wigner transformation for chemical accuracy validation to ensure consistency.
- Chemical accuracy target may still be achievable with Jordan-Wigner transformation (same FCI energy).
- Updated environment energy evaluation to use simulator with molecule Hamiltonian (fix verified).
- Next: Proceed with chemical accuracy optimization using Jordan-Wigner transformation.


### 2026-03-02: Chemical Accuracy Optimization Attempt
- Verified molecule processing for LiH (2,3) with Jordan-Wigner transformation (6 qubits)
- Fixed duplicate excitation penalty: duplicate gives -1 reward but does not terminate episode
- Checked observation space dimensions: no errors
- Tuned PPO hyperparameters: learning_rate=3e-4, n_steps=256, batch_size=64, n_epochs=10, gamma=0.99, ent_coef=0.1
- Adjusted reward function: complexity_penalty=0.0001, energy_weight=10.0
- Ran fast validation (50 episodes): best energy -7.862621 Hartree, error 19.7 mHa (still far from chemical accuracy)
- Discovered UCCSD kernel optimization only reaches -7.862919 Hartree (19.4 mHa error), indicating UCCSD cannot reach FCI for this active space with Jordan-Wigner mapping
- Next steps: Investigate UCCSD energy discrepancy, consider parity transformation with custom circuit builder, or increase search budget
- Discovered FCI energy discrepancy: using full-system FCI instead of active-space FCI; fixed processor.py to compute active-space FCI via CASCI
- Fixed FCI energy reference to active-space FCI (CASCI)
- Re-ran validation with tuned hyperparameters: chemical accuracy achieved (0.298 mHa error) after 1 episode
- Chemical accuracy objective satisfied!
