## Qubit Operator API Investigation (Task 007 prerequisite)
- Investigated Tencirchem qubit operator support (2026-03-22)
- h_qubit_op attribute on UCCSD gives the molecular Hamiltonian as openfermion.QubitOperator
- Tencirchem does NOT have a native QubitUCC class or Pauli string excitation pool
- No 'qubit' or 'pauli' named attributes found in tencirchem namespace
- Approach: Extract qubit-space excitation operators from off-diagonal Hamiltonian terms (X/Y Paulis)
  - These are the anti-Hermitian generators in qubit space (ADAPT-VQE qubit pool)
  - Each operator converted to circuit via exp(-i*theta/2 * P) Pauli rotation decomposition
  - Standard CNOT-ladder decomposition: basis change → CNOT ladder → Rz → reverse
- LiH (2,5) hamiltonian has many X/Y terms: 30+ qubit excitation operators generated
- H2 (2,2) hamiltonian has multiple X/Y terms: 4+ qubit excitation operators generated
